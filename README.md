## Goals

* Build practical DevOps skills through implementation.
* Understand each technology rather than only copying configurations.
* Practice troubleshooting and failure recovery.
* Automate repetitive deployment tasks.
* Apply security throughout the software delivery lifecycle.
* Build a portfolio demonstrating end-to-end DevOps and DevSecOps concepts.
